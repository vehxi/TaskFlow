# Управление проектами и задачами

Руководитель действует только в своих проектах. Почтовый сервис — внешний участник UC-14. При создании задачи отправка выполняется после сохранения; при редактировании и повторном открытии — только при фактическом изменении исполнителя или срока согласно сценариям.

```mermaid
usecase-beta
    direction LR
    actor Manager("Руководитель")
    actor Mail("Почтовый сервис")
    systemBoundary Tracker["Трекер задач"]
        UC04("UC-04. Создание, просмотр и изменение проекта")
        UC05("UC-05. Управление участниками проекта")
        UC06("UC-06. Постановка и назначение задачи")
        UC07("UC-07. Редактирование и перераспределение задачи")
        UC08("UC-08. Просмотр и фильтрация задач")
        UC09("UC-09. Изменение статуса, отмена и повторное открытие")
        UC10("UC-10. Добавление комментария")
        UC12("UC-12. Контроль прогресса и формирование отчёта")
        UC13("UC-13. Экспорт отчёта в Excel")
        UC14("UC-14. Отправка уведомления")
    end
    Manager -- UC04
    Manager -- UC05
    Manager -- UC06
    Manager -- UC07
    Manager -- UC08
    Manager -- UC09
    Manager -- UC10
    Manager -- UC12
    Manager -- UC13
    Mail -- UC14
    UC06 ..> : include UC14
```

Идентификаторы и ограничения доступа раскрыты в [текстовых сценариях](../use-cases.md).

Для просмотра требуется Mermaid 12+ с поддержкой `usecase-beta`. Тип диаграмм находится в бете: [справочник синтаксиса Mermaid](https://mermaid.js.org/syntax/usecase.html).
