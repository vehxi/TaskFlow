# Работа исполнителя

Исполнитель работает только с назначенными ему задачами. UC-09 разрешает ему начало и завершение работы; отмена и повторное открытие доступны только руководителю. Название и описание проекта-участника доступны в рамках просмотра UC-04.

```mermaid
usecase-beta
    direction LR
    actor Executor("Исполнитель")
    systemBoundary Tracker["Трекер задач"]
        UC04("UC-04. Создание, просмотр и изменение проекта")
        UC08("UC-08. Просмотр и фильтрация задач")
        UC09("UC-09. Изменение статуса, отмена и повторное открытие")
        UC10("UC-10. Добавление комментария")
        UC11("UC-11. Учёт собственных трудозатрат")
    end
    Executor -- UC04
    Executor -- UC08
    Executor -- UC09
    Executor -- UC10
    Executor -- UC11
```

Идентификаторы и ограничения доступа раскрыты в [текстовых сценариях](../use-cases.md).

Для просмотра требуется Mermaid 12+ с поддержкой `usecase-beta`. Тип диаграмм находится в бете: [справочник синтаксиса Mermaid](https://mermaid.js.org/syntax/usecase.html).
