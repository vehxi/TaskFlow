# TaskFlow — обзор курсового проекта

TaskFlow — веб-приложение для организации работы команды. В одном проекте руководитель собирает участников, распределяет задачи и контролирует сроки, а исполнители работают с назначенными задачами. Администратор отвечает за учётные записи и общие справочники.

## Что уже работает

| Роль | Возможности |
| --- | --- |
| Администратор | Создаёт учётные записи, назначает роли, редактирует данные и блокирует доступ. |
| Руководитель | Создаёт и редактирует свои проекты, добавляет активных исполнителей и управляет составом. |
| Исполнитель | Видит проекты, в которых участвует, и может открыть их карточки. |

Пользователь может совмещать роли. Сервер проверяет и роль, и доступ к конкретному проекту. Состав проекта нельзя изменить из устаревшей карточки.

**Предусмотрено проектом и ожидает реализации.** Создание, назначение и переназначение задач, сроки и статусы, комментарии и учёт времени, справочники типов и приоритетов, отчёт о прогрессе и просрочках с экспортом в Excel, email при назначении и изменении срока. [Требования и критерии приёмки](requirements.md)

## Как посмотреть приложение

После [подготовки окружения](../SETUP.md) запустите сервер командой `./gradlew bootRun`, а интерфейс — командой `npm --prefix frontend run dev`. Интерфейс откроется по адресу [http://localhost:5173](http://localhost:5173). [Инструкция запуска](../RUNNING.md)

1. Войти как администратор и создать учётные записи руководителя и исполнителя.
2. Войти как руководитель, создать проект и добавить исполнителя в его состав.
3. Войти как исполнитель и открыть этот проект из своего списка.

## Как устроен проект

Интерфейс на React и TypeScript обращается к REST API Spring Boot. Контроллеры принимают DTO, сервисы проверяют права и бизнес-правила, а Spring Data JPA сохраняет данные в PostgreSQL. Flyway применяет миграции. Модель связывает пользователей и роли, проекты и участие, задачи с текущим исполнителем, комментариями и записями времени.

Автономные и интеграционные тесты проверяют вход, роли, управление пользователями и доступ к проектам. Интеграционные проверки используют PostgreSQL. [Тесты и сборка](../TESTING.md)
